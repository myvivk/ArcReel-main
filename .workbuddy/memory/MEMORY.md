# 项目长期备忘

## 文档约定
- 方案文档放 `方案设计/`，按 `N. 名称.md` 编号递增（1 工厂生成 / 2 工厂转写 / 3 镜头宫格 / 4 新路线视频输入）。
- **新主题的方案要独立成文档，不追加进已有方案文档**（用户 2026-10-18 明确要求）。
- 方案文风：写「系统该改成什么样」，不留兼容分支；术语用「分镜/分镜图」；决策用 D-xx、问题用 Px、待拍板用 Rx 编号。
- **方案写法硬性要求（用户 2026-10-20 反馈）**：① 文档最前面必须显式写出「核心流程」主线和顺序（如资产步骤：先生成描述、再出资产图，缺描述会被 `asset_description_required` 准入挡下，补描述不可外置省略）；② 必须写明「页面入口在哪」（去哪个 URL/tab/按钮点）；③ 范围排除要显式点明（如商品 product、广告集不在本方案内）。不要只堆技术细节而把核心流程与入口埋没。
- **术语约定（2026-10-20）**：方案里「剧本」=「工厂源稿」，即项目 `source/short_drama/*.md`（character-bible / series-outline / 各集 `[人物][场景][道具]` 标记稿）。不再把 `scripts/<script_file>.json` 当作与工厂源稿并列的独立「正式剧本」来源；抽取与 AI 补全最高优先级统一为工厂源稿。
