# 工厂制作契约

新项目固定为 `drama / storyboard`，按项目画面比例和视觉风格制作真人或动画短剧。

## 内容与视觉状态

剧情、台词和系列设定以 `source/short_drama/` 原始 Markdown 为真相源。
七类工件通过质量检查后完整入库；`scripts/episode_N.json` 承载 AI 分镜生成的视觉派生状态。
每个 `scenes[]` 条目包含独立镜号、编排时长、原稿锚、出场资产和视觉提示词。
资产描述在 AI 分镜前从工厂工件准备，不要求先有 JSON。

## 依赖顺序

1. 分镜提示词 `image_prompt` 可引用角色、场景和道具资产。
2. 每镜参考素材由分镜提示词生成，联系表与 K 帧关系保存后由用户确认。
3. `video_prompt` 单独编写，可引用已确认参考素材；不与 image_prompt 同批生成。
4. 视频生成保存完整图片关系、声音输入、时长、模型和请求证据。

工厂源稿和视觉来源修订必须一致，变化后先重新 AI 分镜。
模型时长、参考数量和音频能力由服务端能力查询与准入决定，不自行硬编码。
K 帧和参考音频仍可由支持这些输入的供应商接收，供应商能力不构成另一条创作路线。

## 历史数据

历史项目及旧脚本、源文、媒体不清空、不修改模式，不自动转换成工厂工件。
历史读取、迁移、版本选择与已提交任务恢复保持可用；旧生产工具已撤除。
