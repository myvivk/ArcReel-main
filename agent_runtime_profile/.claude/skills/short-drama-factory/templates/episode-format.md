# 单集剧本标准排版（Episode Format）

> 交付格式模板。写完必须过 `python3 scripts/validate_episode.py <文件> --bible references/character-bible.md`（`--format standard|long|manju`，默认自动分档）。

**先定档位再动笔**（篇幅制式，三选一；规格见 `references/hongguo-beat-sheet.md` §三）：

| 档位 | 时长 | 正文体量（实拍 / 漫剧） | 场景 | 单集拍数 | 机检 |
|---|---|---|---|---|---|
| 标准档（默认） | 90～120 秒 | 350～500 / 260～400 | ≤2 | 1 拍 | `--format standard` |
| 长档 | 165～195 秒 | 650～850 / 520～680 | ≤3 | 2 拍 + 中段小钩 | `--format long` |
| 漫剧档 | 60～90 秒 | 260～400 | ≤2 | 1 拍 | `--format manju` |

## 一、 标准档 / 漫剧档模板

```text
第【XX】集：【集名/核心爽点标签】
【所属阶段】：第X幕・（第 X/80 集 ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：五母型之一（生死绝境/极端羞辱/身份暴涨/物证背叛/规则悬念）
【情绪流变】：A ➔ B ➔ C ➔ 绝命断章
【本集时长】：__ 秒（约 __ 字）

[场景]：内景/外景・地点・日/夜｜场景视觉描写      ← 全集 ≤2 个；同一场景只登记一行，不许重复；「｜」后场景外观必填（落入资产描述）
[人物]：名（状态标签｜外观描述）、名（状态标签｜外观描述）  ← 名字须在人物账；「｜」后外观必填，从人物圣经原样抄入
[道具]：名称｜外观描述                    ← 一个道具一行；有戏的道具才登记，「｜」后外观必填；正文里必须写出道具的名字（不要只用「同心结」这类代称，否则分镜清单会漏掉它）

△ 特写/中景：谁 + 做什么动作 + 可见结果（光/物体/身体状态），禁抽象心理词。
角色名（神态短语）：
"台词。"                              ← 常规 12~18 字 / 爆发金句 8~12，硬上限 ≤25 字；对白行 ≥4

【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```

**每一拍写「谁 + 做什么 + 可见结果」（硬规则）**：`△` 行禁止只写标签。屏幕外的东西写成“出现在画面里”的状态——光打在哪、哪只手在动、留下什么痕。

```text
✗ △ 赐死二字映火光            ← 只有标签，没施动者、没落点
✓ △ 冷宫残烛将熄，青白光把墙上“赐死”二字切出硬边，火舌一跳字迹缩回暗处
✗ △ 白绫收紧贴住喉            ← 看不出谁收、什么方向
✓ △ 素白绸面从画右斜入，压住喉侧骤然收紧，绸边在颈上压出一道浅痕
✗ △ 气氛压抑                  ← 抽象状态
✓ △ 残烛一跳，满室暗下半截，帷幔阴影压到床沿
```

**碎片空间 / 闪回拍**：加前缀 `△（碎片·冷宫）…`，并在拍内写出冷光、叠影或画外声。它不是本幕空间、不占场景名额，但**必须出现在首镜**——下游分镜会检查首镜有没有这段碎片。

```text
✓ △（碎片·冷宫）破窗的冷白月光斜切进来，在绣楼门缝投成一道窄长冷光，与暖红烛火叠在一起
✓ △（碎片·冷宫）画外传来唱报声：“沈氏，即刻自尽。”声音穿过门缝，烛火随之猛地一颤
```

**拍数（机检 E12）**：`△` 动作行与台词行各算一拍，一拍一句、不合并概括；本集拍数须 ≥ `ceil(本集秒数 ÷ 2)`（标准档 105 秒 ≥53 拍，长档 180 秒 ≥90 拍，漫剧档 75 秒 ≥38 拍）。

## 二、 长档模板（约 3 分钟）

```text
第【XX】集：【集名/核心爽点标签】（长档·约3分钟）
【所属阶段】：第X幕・（第 X/40 集 ｜ 单元A ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：五母型之一
【情绪流变】：A ➔ B ➔ C ➔ D ➔ 绝命断章
【本集时长】：__ 秒（约 __ 字）
【本集结构】：双回合（回合A ____ ➔ 回合B ____）    ← 本集时间骨架：钩 0~8s / 回合A 8~80s / 小钩≈90s / 回合B 95~170s / 断章 170~195s

[场景]：内景/外景・地点・日/夜｜场景视觉描写        ← 全集 ≤3 个，第 2/3 场必须是升级场（换空间/换对手/换压力等级）；「｜」后场景外观必填
[人物]：名（状态标签｜外观描述）、名（状态标签｜外观描述）  ← 「｜」后外观必填，从人物圣经原样抄入
[道具]：名称｜外观描述                    ← 一个道具一行；「｜」后外观必填

△ 特写/中景：钩子——直接切入冲突顶点，禁铺垫。
角色名（神态短语）：
"台词。"                              ← 回合A：施压 ➔ 反驳，反驳必须带代价或新信息；对白行 ≥8

【本集中段小钩】：≈90 秒处的新信息/新威胁/反转半步，只抬价不爆点。（机检必查）

△ 中景：回合B —— 升级施压（新证据/新代价/新人证）。
角色名（神态短语）：
"台词。"                              ← 升级反驳/翻盘未遂，禁复读回合A 话术
△ 中景：情绪顶点落地 + 静默反应镜头

【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```

**拍数（机检 E12）**：同上——`△` 动作行与台词行各一拍，本集拍数须 ≥ `ceil(本集秒数 ÷ 2)`（长档 180 秒 ≥90 拍）。

**写前**：读台账 + 回合表定位本集档位与拍数；**写后**：更新台账四账 + 按档跑机检。
