这段文字是 K0→Kn 的**运动增量**，不是第二遍画面。分镜提示词与已确认的 K 帧已经固定了主体长相、服装、构图、景别、机位、光线与环境状态；action 只写这些状态之间**怎么变**。

- **只写变化，不写静帧**：不重写长相、服装、景别、机位、构图、光线或背景状态；只有它们发生变化时才写变化本身（「烛焰在一秒内压低」「光由暖黄转冷」），不写「她穿着深蓝长裙」这类状态句。
- **不复述镜头语言**：运镜只由 camera_motion 字段承载，action 不出现「镜头推近」「切中景」「机位」「景别」。
- **不复述定格画面**：分镜镜头块已经固定在某一帧上的姿态与状态（「低头看向左手腕」「从床沿坐起」）只写时间上的变化量；K0→Kn 之间新增的动作（入画、落座、递物）写触发、过程与落点，不连静止外观一起重写。
- **不要复用原句**：保留动作义务，但不要照抄分镜提示词或 K 帧里的原句/短语；同一个动作写成「从什么状态到什么状态」，例如把「低头看向左手腕」改写成「视线落到腕间，腕骨从袖口里露出来」。
- **保留覆盖下限**：每个 K 帧间隔至少保留一个分镜已经写出的必要动作/状态变化；删的是静帧复述，不是动作本身。不能为了简短把某个 K 之间的动作删掉。
- **写完逐句删**：一句话删掉后，观众仍能从 K 帧看出同样的信息，这句就是静帧复述，删掉；但删完必须回读一遍，确认没有丢 K 之间的动作。
- 按该分镜的 duration_seconds 拆成连续时间段，格式统一写作 `0-3秒：...`、`3-6秒：...`，每个时间段单独一行（换行分隔），覆盖完整时长且不重叠；短分镜至少写一段 `0-<时长>秒：...`。首段从 K0 的可见状态起，末段落到 Kn 的可见状态。
- 每段只写 1–2 个可见变化，按「触发 → 过程 → 落点」组织；动作量与该分镜时长匹配：5 秒级通常完成一个连贯动作 + 一个细节互动，8 秒级可承载一次动作过渡（「抬头—对视—开口」），更长的分镜保持单一低缓的动作主线，随时长递增段数，而非叠加多条并行动作。
- 动词应描述物理可观察动作（伸手 / 转身 / 摩挲 / 投向 / 收紧），避免内心动词。角色、场景、道具需要引用已登记资产时使用 `@资产名` 或 `@[资产名]` 记号，不要写成最终模型里的 `Action`、`Camera_Motion`、`Dialogue`、`Avoid` 包装字段。
   正例：「0-3秒：@林清抬头的瞬间，眼尾由松转紧，指尖从信纸边缘松开又压回去。3-6秒：窗外的雨势变密，桌面雨痕影子向桌角缓慢拉长。」——每段只写状态之间新增的变化，不复述静帧。
   反例（复述静帧）：「0-3秒：@林清坐在窗边，左手撑着下巴，桌上摊着信封与怀表，半边脸笼在蓝灰色阴影里。」——这是分镜提示词已经定格的画面，没有写任何变化。
   反例（复述运镜）：「3-6秒：镜头缓慢推近，切到 @林清 的近景。」——运镜属于 camera_motion，action 不写。
- **已登记的角色一律用 `@资产名` 指代，不写「她 / 他 / 身影 / 女子」**：代词和「微驼身影」这类外貌描述绑不上资产图，模型会自己造一张脸；首次出现时打 `@`，后文用名字即可。道具同理，有登记的道具（红绳、铜镜等）第一次出现就要 `@`。
- **输出前自检**：逐段核对——每段是否只写变化；有没有复述静帧或运镜；首段是否接 K0、末段是否落到 Kn；时间段是否从 0 起连续覆盖 duration_seconds；每个 K 间隔是否至少保留一个必要动作；**有资产的角色/道具是否都用了 `@资产名`、名字能否解析到已登记资产（有没有写成「她 / 他 / 身影」）**；声音是否只在 ambiance_audio；台词是否没有进入 action。
