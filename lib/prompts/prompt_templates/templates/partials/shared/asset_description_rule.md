资产 `description`（角色、场景、道具、商品）按以下标准生成或修改，输出为可直接用于资产登记的简洁、连贯中文描述，不输出图片布局、固定开头/结尾、反向提示词或过程解释。

1. 只写原文或用户明确设定支持的事实；项目内其他设定工件（如人物圣经、系列大纲、单集原文的 `[人物]`/`[场景]` 标记行）写明的设定同样算依据，应当采用。上述依据都没有的关键视觉设定（年龄、身份、服装、配饰等）按题材做合理、自洽的补全并写足，不必逐项向用户确认；品牌、商标、广告卖点等商业信息无依据仍不得添加。不得写出与已有设定冲突的内容。
2. 角色：依次写设定支持的年龄、性别与体态；脸型、五官、肤色和辨识特征；可观察到的眼神、表情、姿态；发型、服装、颜色、面料与配饰。性格词不能擅自改写成外貌事实；不得用抽象品性推断“精明、城府、威严、坚毅”等视觉特征；来源未提及的身高、服装、首饰或道具，可依据设定工件补全，工件也没有的按角色定位合理设定，但不得与已有设定冲突。已有描述的修改只落实用户明确要求并保留其他设定。
3. 场景：原文与项目设定工件明确出现的地点、空间结构、时间/天气和陈设照写；不得依据场景名称补造年代、地域、建筑风格、光线、色调或氛围，但设定工件（如系列大纲、单集原文的场景行）支持时按工件写，工件也未写明时按场景功能与项目画风合理补全，保持整体自洽。
4. 道具与商品：只描述明确提及的类别、形状、材质、颜色、标识和状态；不推测品牌、型号、功能、材质或未写明的细节。商品尤其不得添加原文或用户未提供的包装、商标和卖点。
5. 角色衍生描述只写相对本体发生变化且有依据的部分；不得重复或虚构本体未变化的外观。适用于所有资产类型的 `description` 都是内容设定，不是最终图片提示词；白底、视图布局、灯光、材质控制、Avoid 等固定图像指令由服务端模板生成，不得写入描述。
