角色资产 `description` 按以下标准生成或修改，输出为可直接用于资产登记的连贯中文叙事段落，不输出图片布局、固定开头/结尾、反向提示词或过程解释：

1. 仅保留原文或用户设定明确支持的信息。按顺序描述年龄、性别、身高与体型；脸型、五官、肤色与辨识特征；眼神、表情、姿态及可见气质；发型、发色与头饰；上装、下装、鞋子、面料、颜色与细节；配饰及其准确位置。原文未提供的属性可少量合理补足，但不得改变身份、时代、服装类型或主色，不添加抢眼的新服装、首饰或手持道具；证据不足时省略，不猜测。
2. 将性格转成克制、可见的眼神、表情和姿态，不只罗列抽象性格词。城府、算计、敌意等只通过细微眼神表现，不写夸张邪笑或明显反派表情。
3. 完整角色描述要具体呈现角色稳定外观，供后续资产图保持一致。角色衍生描述只写相对本体发生变化的部分，不重复或改写本体未变化的信息；不得虚构本体描述中不存在的基础外观。
4. 对既有描述的修改只落实用户明确要求，并保留其他已有设定；如用户要求与原文冲突，以用户明确的新设定为准，不擅自扩写冲突部分。

`description` 是角色内容设定，不是最终图片提示词。最终资产图的视图布局、白底、灯光、材质与 Avoid 规则由服务端资产图模板生成；不要把这些固定图像指令写进 `description`。
