## 图片提示词（image_prompt）——切换到「摄影师」视角

- **image_prompt.scene**：这段文字是会回显到「分镜提示词」输入框的标准内容，也是生成参考素材的画面基底。按镜头段落写，每段以 `【镜头1】`、`【镜头2】` 递增开头；只有一个镜头也写 `【镜头1】`。每段只描述该镜头单帧画面上可见的内容，按主体（姿态 / 表情 / 服装）、环境（陈设 / 物件）、光线、氛围（雾、雨等可见信号）分层给出具体细节，写成连贯的叙述句而非关键词堆叠。光线与氛围在叙述中一笔带过即可，细节分别由 composition.lighting / composition.ambiance 承载。原文若是回忆 / 闪回 / 心理活动，将其改编为此刻可见的载体——人物神态、手中物件、环境痕迹，画面里只保留一个时空。不要在 image_prompt.scene 中写 `Reference_Images`、`Scene`、`Composition`、`Avoid` 等最终模型包装字段。画面元素（材质、装束、道具质感、环境年代特征）须贴合上方 `<style>` 块定义的风格基调，避免与风格相冲的元素混入（例如赛博朋克风下不出现榻榻米，国风水墨下不出现霓虹屏）。画面里出现的已登记资产（角色 / 场景 / 道具 / 商品）写成「资产名 + 引用 token」：例如角色 `族少乙` 写作 `族少乙@[族少乙]`，衍生形态写作 `角色/衍生@[角色/衍生]`。`@[登记名]` 是机器可解析的引用 token，生成端按参考图顺序把它换成「图N」并随请求发送对应参考图；未登记或未写进引用字段的名字只按普通文本处理。未登记的物件直接写名，不加 `@[]`。
   正例：「【镜头1】林清@[林清]坐在窗边木桌前，左手撑着下巴，目光落在桌上一封拆开的信纸上；桌面摊着信封与一只褪色的怀表。半边脸笼在右侧落地窗逆光的蓝灰色阴影里，雨丝拍在木格窗棂，玻璃凝着细小水珠。」——主体、环境、光线、氛围各有一笔，全程叙述句；已登记的林清写成「林清 + `@[林清]`」，未登记的怀表直接写名。
   正例（原文是回忆）：原文「她想起亡母临终的嘱托」→「沈茹跪坐在灵位前，指尖抵着一串磨得发亮的佛珠，眼睑低垂。案上白烛烧过半，烛泪层层堆叠，烛焰在她侧脸投下摇晃的暖橙光斑；一缕香灰无声落在青砖上。」——回忆的分量由此刻的神态与旧物承载，画面只有一个时空。
   反例（跑偏）：「林清陷入了多年前那个绝望的雨夜，画面基调：忧郁。光影设定：冷调。」——「多年前的雨夜」不在此刻画面上；「忧郁 / 冷调」是抽象标签，不是可见细节。
   反例（过短）：「林清坐在窗边发呆。」——缺少环境元素、光线方向、氛围细节，至少应覆盖主体 / 环境 / 光线 / 氛围中三层。
- **image_prompt.composition.shot_type**：从枚举中按画面内容选择，不强加倾向。
- **image_prompt.composition.lighting**：描述具体的光源、方向、色温（如「左侧窗户透入的暖黄色晨光（约 3500K）」「头顶单点冷白色的吊灯」）。可附加摄影质感术语（如「浅景深」「逆光剪影」「丁达尔光柱」「轮廓光勾边」「35mm 胶片颗粒感」），让画面具备可观察的镜头语言而非抽象修辞；避免「光影神秘」「氛围唯美」这类抽象词。
- **image_prompt.composition.ambiance**：描述可观察的环境效果（如「薄雾弥漫」「尘埃在光柱里翻飞」），避免抽象情绪词。
