## 图片提示词（image_prompt）——切换到「摄影师」视角

- **image_prompt.scene**：这段文字是会回显到「分镜提示词」输入框的标准内容，也是生成参考素材的画面基底。它描述一个 12-15 秒分镜段的画面内容，不等同于单帧图片说明。按镜头段写，每段以 `【镜头1｜中景】` 起头、序号从 1 连续递增，景别必填（写进标记，如 `【镜头2｜特写】`）；只有一个镜头也写 `【镜头1｜景别】`。景别之后的首句写机位与运镜（如「平视机位，缓推。」），随后是连贯叙述句（不是关键词堆叠），按主体（实名 + 姿态 / 表情 / 动作）→ 环境（陈设 / 物件）→ 光线氛围（雾、雨等可见信号）分层各给一笔；光线与氛围在叙述中一笔带过即可，细节分别由 composition.lighting / composition.ambiance 承载。原文若是回忆 / 闪回 / 心理活动，优先改编为此刻可见的载体——人物神态、手中物件、环境痕迹；确需保留前世 / 闪回空间时，必须写成显式的碎片镜头（正文以「闪回：」起头，其后仍先写机位与运镜，再写冷光、硬切、光转之类的断点信号），不得与此刻空间混进同一格。画面里出现的本分镜出场资产（角色 / 场景 / 道具）写成「名字 + 引用 token」：已登记的林清写作 `林清@[林清]`，衍生形态写作 `角色/衍生@[角色/衍生]`——token 只能写出场资产清单里的名字，清单外的已登记资产写裸名，未登记的物件直接写名、不加 `@[]`；每个镜头段第一个主体写实名，句内后续才可用代词。`@[登记名]` 是机器可解析的引用 token，生成端按参考图顺序把它换成「图N」并随请求发送对应参考图。不要在 image_prompt.scene 中写 `Reference_Images`、`Scene`、`Composition`、`Avoid`、`视觉参考` 等最终模型包装字段，不要把资产登记外观整份抄进正文——外观一致性由参考图承载，正文只写本镜头可见的动作与神态。画面元素（材质、装束、道具质感、环境年代特征）须贴合上方 `<style>` 块定义的风格基调，避免与风格相冲的元素混入（例如赛博朋克风下不出现榻榻米，国风水墨下不出现霓虹屏）。
   正例：「【镜头1｜中景】平视机位，缓推。林清@[林清]坐在窗边木桌前，左手撑着下巴，目光落在桌上一封拆开的信纸上；桌面摊着信封与一只褪色的怀表。半边脸笼在右侧落地窗逆光的蓝灰色阴影里，雨丝拍在木格窗棂，玻璃凝着细小水珠。」——景别进标记、机位运镜在首句，主体、环境、光线各有一笔，全程叙述句；已登记的林清写成「林清 + `@[林清]`」，未登记的怀表直接写名。
   正例（原文是回忆）：原文「她想起亡母临终的嘱托」→「【镜头1｜近景】固定机位。沈茹跪坐在灵位前，指尖抵着一串磨得发亮的佛珠，眼睑低垂。案上白烛烧过半，烛泪层层堆叠，烛焰在她侧脸投下摇晃的暖橙光斑；一缕香灰无声落在青砖上。」——回忆的分量由此刻的神态与旧物承载，画面只有一个时空。
   反例（跑偏）：「林清陷入了多年前那个绝望的雨夜，画面基调：忧郁。光影设定：冷调。」——「多年前的雨夜」不在此刻画面上；「忧郁 / 冷调」是抽象标签，不是可见细节。
   反例（过短）：「林清坐在窗边发呆。」——缺少环境元素、光线方向、氛围细节，至少应覆盖主体 / 环境 / 光线 / 氛围中三层。
   反例（引用跑偏）：「角色@[林清/二十岁上下，长发及腰] 站在窗边。」——「角色@」是泛化前缀，token 里堆的是资产登记外观；正确写法是「林清@[林清]站在窗边，长发及腰在灯下泛出涩白」。
- **连续性与帧链（同一分镜内）**：除第一条镜头外，每条镜头的**首句必须出现下列承接词或位移动作之一**——承接、仍、又、继续、随即、接着、随后、转身、回身、起身、站起、坐下、俯身、直起、走近、走到、退开、后退、上前、凑近、靠近、绕过、跨过、放下、抬起、收回、松开、接过、递、抽出、推开、拉上、撑、扶、按住、压住、盯、望、看向、扫向、循声。闸门按字面判，只有闪回或时间跳可以断，断点也必须写明确的切点词（闪回 / 硬切 / 黑场 / 光转 / 跳切）。
- **分镜之间**：本条分镜的首镜要接住上一分镜末镜的人物、视线或声源；确实换场或跳时间，就在首镜写断点标记（硬切 / 黑场 / 光转 / 闪回）。上一分镜没有人物在场时，首镜写「承接上一镜的…」（承接它的烛火、门声、桌面陈设），质检认可这种承接。
- **首尾持物接续**：下一条分镜的首镜必须复述上一分镜末镜的人物位置、手、持物、服装和光线；当前分镜要出现上一镜没有的道具（托盘、白绫、药碗等）时，必须在首镜或次镜写出它怎么进入——内侍托入、苏嬷嬷接过、放到桌上——不能让它凭空已经在手里。
- **镜头目的与轴线**：每个镜头块结束时，观众必须多知道一件事，或关系 / 压力发生一次变化；相邻两镜同景别、同机位、同关系时，这次切镜没有职责。同一场戏保持 180° 轴线同一侧，相邻镜头的视线方向要能对上；确需换轴，写清动机（人物移动 / 过肩 / 主观），不要无理由反打。左 / 右一律指屏幕方向，人物自己的左右要写明。
- **同场光位**：同一场景同一时段的主光方向、色温关系与明暗对比保持一致；只有剧情写明变化时才写变化成因。
- **画面只写看得见的内容**：不写声音（唱报、宣读、喊声、听见、画外音等）和抽象情绪；声音只由 `utterances` / `ambiance_audio` 承载。道具只出现在原文或场景描述明确给出的位置；来自其他时空的赐死物只能作为叠影 / 闪回，不得摆进当前空间。
- **首末帧**：第一条镜头写清起始状态（人物位置、姿态、手持物、光线），最后一条镜头收在稳定定姿（动作完成后的状态，不要停在半途），中间的镜头写过程。宫格的首帧取首镜、末帧取末镜。
- **关键帧**：需要当关键瞬间的镜头，在正文开头写「关键帧：」——梦境→现实、人物入场、失态、断章这类转折。宫格优先按这些镜头挑帧，不按镜头数平均切。
- **台词预算**：每一幕的台词按约 5 字/秒估算，不得超过「幕时长 − 镜头数 × 1.2 秒」。说话多的幕少切镜头，动作多的幕才多切。
- **碎片空间**：分集规划写明「某地点仅作压在绣楼内的声画碎片」时，必须把它写进**单独的碎片镜头块**——冷光、叠影、画外声都算；不得省略，不得把发生在那边的动作搬进本幕空间，也不得在同一 `【镜头N】` 块里先写碎片、再写硬切回当前空间。碎片块之后另起一块写当前空间，切点写在块与块之间，不写在块内。
- **空镜（画面里没有人物）**：不要求神态，但必须写清光影或环境在动（烛火摇曳、门缝透进冷光、帷幔被风带起），不能写成静止的布景说明。
- **事实边界**：道具的形状与来路、人物的穿戴与持物以资产登记为准（例如白绫的同心结系在末端、旧红绳戴在腕上），不得把登记以外的来路写成既成事实。
- **image_prompt.composition.shot_type**：从枚举中按画面内容选择，不强加倾向。
- **image_prompt.composition.lighting**：描述具体的光源、方向、色温（如「左侧窗户透入的暖黄色晨光（约 3500K）」「头顶单点冷白色的吊灯」）。可附加摄影质感术语（如「浅景深」「逆光剪影」「丁达尔光柱」「轮廓光勾边」「35mm 胶片颗粒感」），让画面具备可观察的镜头语言而非抽象修辞；避免「光影神秘」「氛围唯美」这类抽象词。
- **image_prompt.composition.ambiance**：描述可观察的环境效果（如「薄雾弥漫」「尘埃在光柱里翻飞」），避免抽象情绪词。
