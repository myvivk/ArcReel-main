# 短剧工厂制作流程 {#workflows}

ArcReel 使用短剧工厂完成内容创作和视频制作。项目创建后依次完成工厂交稿、资产准备、AI 分镜、参考素材确认、独立视频提示词、视频生成和剪辑导出。

## 1. 创建工厂项目 {#two-dimensions}

新建项目时填写名称、画面比例、视觉风格、全剧总集数、单集目标和模型配置。系统固定使用剧情分镜制作，不提供创作类型或生成路线选择。真人与动画视觉风格都可使用。

```mermaid
flowchart LR
    A["创意简报 / 工厂续写 / 工件导入"] --> B["工厂质量检查与七类工件入库"]
    B --> C["角色 / 场景 / 道具资产"]
    C --> D["AI 分镜与分镜提示词"]
    D --> E["逐镜 K 帧参考素材确认"]
    E --> F["独立视频提示词"]
    F --> G["视频与声音"]
    G --> H["剪辑 / 成片 / 剪映草稿"]
```

## 2. 工厂交稿与内容阅读 {#content-sources}

### 工厂生成 {#drama-flow}

「AI 原创剧本」支持新建、续写和连写。填写题材、创意简报、篇幅档位和全剧总集数，将指令交给 Agent。Agent 读取已有系列工件，并调用项目配置的强文本模型。

每集依次经过初稿、医生精修、单集机检、返修、台账更新、系列机检和合规检查。每个批次通过后立即保存；机检失败、报告未通过或工件不完整时，整批拒绝入库。

### 工件目录导入 {#artifact-import}

已有工厂交稿时，在概览、剧本页或分镜页打开「导入剧本」，选择包含工件的目录。系统检查相对路径和七类工件，按 Markdown 原文入库：

- 人物圣经：`character-bible.md`；
- 全剧大纲：`series-outline.md`；
- 连续性台账：`ledger.md`；
- 分集规划：`episode-plan/episode_NN.plan.md`；
- 集正文：`episodes/episode_NN.md`；
- 机检报告：`reports/episode_NN.machine.md`；
- 合规报告：`compliance/episode_NN.compliance.md`。

这些文件保存在 `source/short_drama/`。系列工件可复用已有版本，每个交付集必须同批提交分集规划、正文和两类报告；报告须有明确最终结论 `结果: PASSED`。入库会重新执行质量检查。普通小说、PDF 或单篇 Markdown 正文不能直接通过这份工件契约。

### 故事规划与本集剧本 {#story-planning}

「故事规划」页只读展示人物圣经、全剧大纲、台账和分集规划；集页的「剧本」视图展示 `episodes/episode_NN.md` 原文。质量报告保存在项目目录，页面暂不展示。

工厂正文是剧情和台词的真相源。正文返修需要重新经过工厂质量流程并提交完整工件；页面不直接改写正文。交稿不会生成视觉制作 JSON，也不会自动登记资产。

## 3. 资产与 AI 分镜 {#content-modes}

### 本集资产 {#stage-reference-assets}

在本集「资产」中核对角色、场景和道具，补齐登记、描述与资产图。未登记或缺描述的资产会阻止 AI 分镜。跨集复用资产可减少人物外观、服装和场景漂移。

### AI 分镜 {#drama-mode}

进入「分镜」，按源稿和已登记资产生成分镜段及分镜提示词。分镜时长采用项目配置。选择保守、标准或增强优化强度；已有分镜可整体重做，也可只重写所选分镜。未选分镜保留。

AI 返回结果必须覆盖源稿内容，保留台词与来源锚点。校验失败会带原因返修，重试用尽后报错，不交付机械切分结果。`scripts/episode_N.json` 保存视觉制作派生状态，不替代工厂正文。

## 4. 参考素材与独立视频提示词 {#video-production-routes}

### 分镜详情与 K 帧 {#storyboard-image-route}

分镜详情从上到下排列「引用」和「提示词」。提示词区依次为：

1. **分镜提示词**：使用「引入引用资产」插入角色、场景和道具，图像生成携带对应资产图。
2. **参考素材**：从分镜提示词生成同一分镜的连续关键帧。默认 2×2，可选择 2×3 或 3×3；从左到右、从上到下编号为 K0、K1 等。生成后检查宫格图，点「确认参考素材」完成切分和绑定。
3. **视频提示词**：参考素材确认后独立编写，使用「引入参考素材」插入 K 帧编号。分镜提示词和视频提示词不能在同一次生成中编写。

取消参考素材编辑不会保存。修改宫格规格后，需要重新生成并确认素材，才能从详情页生成视频；素材改变后，已有视频提示词会提示建议重写。每份素材只包含一个分镜的连续 K 帧。

### 输入与接续 {#shot-continuity}

视频生成携带整组关键帧，每格只发送一次，并记录关键帧与宫格联合图的完整关系。模型必须支持所选规格对应的参考图数量及首尾帧输入；超过上限时整批阻止入队，系统不会裁掉关键帧。

相邻分镜优先从前镜视频的实际尾帧接续，其次使用用户设置的尾帧快照，再次使用前镜宫格末格。没有可用接续来源时，以本镜第一格开场；本镜以最后一格结束。重新生成视频不会覆盖用户保存的尾帧快照。

角色参考音频按台词中角色首次发言的顺序传入，受模型音频段数和总时长限制。需要声音与图像绑定的模型，还须为发言角色指定对应关键帧。

## 5. 历史项目与升级 {#historical-projects}

旧旁白、广告和参考生视频项目的数据文件、媒体和版本记录保留，用于读取、归档和已有剪辑；它们不能通过旧入口或通用入口新生成内容。旧模式字段不会被改写为工厂项目，也不会从旧 JSON 自动拼造七类工件。

重新制作需要创建工厂项目，并按完整工厂交稿契约提供内容。已提交且可恢复的供应商任务继续按保存的任务 ID 恢复，下载失败仍可重试下载，避免重复下单。

内置 Agent 配置按文件指纹更新，移除未修改的旧内置工具说明，保留用户定制。外部 Agent 应重新获取当前 MCP 工具清单，并使用工厂生成、工件入库和提示词编写工具。

## 6. 标准生产阶段 {#production-stages}

工厂制作按以下阶段核对，先用少量样片验证，再扩大批量。

### 阶段 1：项目目标 {#stage-project-goal}

明确：

- 发布平台；
- 比例；
- 目标时长；
- 受众；
- 画面风格；
- 预算上限；
- 是否需要旁白；
- 是否需要剪映继续编辑。

### 阶段 2：内容结构 {#stage-content-structure}

确认：

- 剧情顺序；
- 分集边界；
- 每个分镜的目的；
- 每集出场的角色、场景和道具；
- 不应被改写的内容。

核对工厂源稿、系列连续性和分集规划后再准备资产。需要改剧情或台词时，回到工厂返修与工件入库；需要改画面时，调整 AI 分镜或提示词。

### 阶段 3：资产图 {#stage-assets-check}

确认：

- 主要角色；
- 常驻服装；
- 场景；
- 关键道具；
- 风格参考。

#### 合并重复登记的资产 {#merge-assets}

同一个人、地点或物件被登记成两个资产时（例如「老王」和「王建国」），在其中一张资产卡片的菜单里选「并入…」，再选要保留的同类型资产。只有角色、场景和道具可以合并。

合并后，各集脚本规划、正式脚本、草稿和提示词正文里的引用都改指保留的资产，被并资产的名字和别名记为保留资产的别名。被并角色名下的衍生迁到保留角色名下，与保留角色已有衍生同名的，并入已有的那个。保留资产的描述、资产图和其他设置不变。

角色还可以选「并为衍生」：被并角色成为保留角色的一个衍生，沿用原来的描述，衍生资产图待生成。画面引用改指这个衍生，台词的说话人改为保留角色本人，被并角色的名字不记为别名。

被并资产的描述、资产图及版本历史、声音设置、原图和参考音频都不保留，合并无法撤销。确认前，对话框按集列出将改写的引用数，以及将过期的分镜图和视频数，并展示被并资产的描述，便于把需要的内容复制到保留资产。

#### 删除资产 {#delete-assets}

在资产卡片的菜单里选「删除」。确认前，对话框先检查各集脚本规划、正式脚本、草稿和提示词正文里的引用：

- 有引用时，写明被哪些集引用、共多少处。删除不改写这些引用，引用它的分镜在生成时会被拦下。需要保留这些引用时，点「改为并入…」，把它[并入另一个同类型资产](#merge-assets)。
- 没有引用时，只提示删除后无法恢复。

删除角色时，它名下的衍生一并删除。删除无法撤销。

### 阶段 4：少量样片 {#stage-sample-clips}

先制作：

- 1～2 个角色；
- 2～4 个分镜；
- 1～2 个视频片段；
- 一小段旁白。

样片通过后再扩大批量。

### 阶段 5：批量生产 {#stage-batch-production}

开始前确认：

- 并发和 RPM；
- 费用预估；
- 供应商额度；
- 失败重试策略；
- 磁盘空间。

#### 当前、过期与缺失产物 {#artifact-currency}

ArcReel 会按产物生成时的直接输入判断状态：

- **当前**：正式产物与当前项目、剧本和所选版本一致；
- **过期**：正式产物仍然存在并可预览、导出，但它生成后相关输入已发生变化；
- **缺失**：没有可用的正式产物，需要生成；
- **阻塞**：项目引用或产物记录损坏，需先修复，系统不会把它当成缺失项自动付费重做。

默认批量生成只补齐缺失项，当前和过期产物都会保留。修改提示词、角色、旁白或其他输入后，如果希望刷新已有结果，请显式选择对应分镜重新生成。仅在目录中出现同名文件并不代表它是正式产物；项目必须保留剧本中的产物引用或可验证的版本记录。

### 阶段 6：质检和导出 {#stage-qa-and-export}

检查：

- 角色一致性；
- 场景连续性；
- 动作和视线；
- 旁白同步；
- 字幕；
- 片段顺序；
- 总时长；
- 最终分辨率；
- 剪映导出是否能打开。

## 7. 审核闸门 {#review-gates}

ArcReel 的优势不是“跳过审核”，而是让审核发生在返工成本较低的位置。

| 审核点 | 不通过时应做什么 | 不应做什么 |
|---|---|---|
| 工厂质量检查 | 返修正文、系列连续性和工件报告 | 继续制作不合格正文 |
| 角色资产 | 重做角色设计或描述 | 带着错误角色批量生成分镜 |
| 少量分镜 | 修正构图和风格 | 直接生成整集视频 |
| 少量视频 | 调整模型、参数和动作描述 | 反复用高成本模型盲试 |
| 旁白试听 | 修正音色、语速和文本 | 一次生成全部音轨 |
| 成片预览 | 调整顺序、时长和转场 | 直接发布未质检版本 |

## 8. 一致性实践 {#consistency-practices}

### 角色 {#consistency-characters}

- 保持固定的年龄、发型、体型和核心服装描述；
- 角色资产中减少不必要背景；
- 不同主要角色要有明显区分特征；
- 换装应作为明确剧情状态，而不是提示词随机变化。

### 场景 {#consistency-scenes}

- 为重要场景建立资产图；
- 固定空间方位和主要装饰；
- 同一段剧情不要频繁切换不必要的光线和时间；
- 记录角色在空间中的位置。

### 道具 {#consistency-props}

- 对剧情关键物品建立道具资产；
- 不让模型自行补全重要文字、Logo 和结构；
- 发现细节漂移时优先重做对应分镜，不要通过后续分镜掩盖。

## 9. 成本控制实践 {#cost-control-practices}

- 先低成本样片，后高质量批量；
- 角色设计和关键封面使用高质量模型；
- 普通分镜使用更均衡的模型；
- 先确认图片，再生成视频；
- 单个失败分镜单独重做；
- 每次批量前查看费用预估；
- 不在模型配置不确定时提交整集；
- 保存可复用角色和场景资产。

## 10. 完成定义 {#definition-of-done}

一个剧集或短片至少满足以下条件才算完成：

- 内容结构已确认；
- 主要资产已确认；
- 所有分镜均有明确用途；
- 角色和关键道具没有明显身份漂移；
- 视频片段可衔接；
- 旁白和字幕已校对；
- 实际费用已检查；
- 成片或剪映草稿可正常打开；
- 项目已归档或备份。
