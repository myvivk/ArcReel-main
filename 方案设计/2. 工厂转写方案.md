# 短剧工厂转写方案

> 读工厂单集原文 → 切分镜 → 写 `scripts/episode_N.json`。
> 分镜 = 一段视频的描述。本文只管转写这一步；参考图、出图、出视频都是后面的步骤，不在本文。

## 一、概念定义

| 概念 | 定义 |
|---|---|
| **分镜** | 脚本里可独立生成的一段视频（12~15 秒）。 |
| **分镜正文** | 这段视频的描述：谁、在哪、连续发生什么、镜头怎么走、什么声音、台词归属。是该段视频唯一的内容真相。 |
| **台词** | 分镜的一个字段（`utterances`）：谁说的、说了什么。供配音、字幕、口型使用。 |
| **资产** | 角色 / 场景 / 道具的名字 + 外观描述。转写负责登记；登记后的用途不在本文范围。 |
| **切分镜** | 把工厂单集原文按拍（动作行 / 台词行）切成 N 段。 |

## 二、正文密度：12~15 秒不是四行字能撑住的

一段 12~15 秒的视频，要拍得紧凑丰满，正文必须给到**每秒至少一个可拍的细节**，即 8~15 个动作拍，包括：

- 环境**参与动作**：雨水渗进门缝、货箱挡路、塑料筐被踢开——不是一句"夜，仓库"的背景板；
- 人物**连续动作链**：进门 → 顿住 → 扫视 → 踢开筐 → 走近，一步接一步，不能只有一个"推门而入"就跳到台词；
- **对手戏反应**：A 说狠话时 B 在干什么（摁灭烟头、别过脸）——沉默的反应也是内容；
- 台词**前后有承接**：说话前的姿态、说完后的动作，避免"站定→念台词→切镜头"的空档。

**密度从哪来**：从工厂单集原文来。转写是忠实映射，不注水——原文只有一句"推门而入"，转写不会替它编出踢筐、扫视。所以密度要求落在**工厂写原文的环节**（`1. 工厂生成方案.md` 的单集正文要求）：动作行要写足连续的拍，一拍一个可执行的动作，而不是一句概括。

## 三、转写做什么

1. 读 `source/short_drama/episodes/episode_NN.md`；
2. 按 `[场景]` 块 / `△` 动作行 / `角色（神态）：台词` 行切分镜，每段落在 12~15 秒窗口（`STORY_SCENE_WINDOW_SECONDS`），切点只落在拍与拍之间，不劈断台词；
3. 每段分镜产出：
   - `text`：这段视频的描述——环境 + 连续动作 + 神态 + 镜头走法 + 台词归属（`@[角色]{台词}`）；
   - `utterances`：从原文台词派生，逐字保留；
   - 引用：该段涉及的角色名、场景名（有道具行则含道具名）；
4. 登记资产：名字 + 外观描述写进 `project.json`，已存在的不覆盖；
5. 回执：分镜数、总时长与 `【本集时长】` 的差额、缺描述的资产清单。

转写不写提示词、不生成任何图片或视频。

## 四、正文映射规则

工厂原文（节选，按密度要求写足后）：

```
【本集时长】：120 秒
[场景]：城郊仓库｜水泥地、铁门、单侧顶光
[人物]：林辰（隐忍龙王｜三十岁上下，寸头，旧夹克）、陈峰（嚣张富二代）
△ 顶光从铁门缝隙切进来，照在湿漉漉的水泥地上，雨水顺着门缝往里渗。
△ 林辰侧身挤开半掩的铁门，夹克肩膀浸出深色，在门口顿了一秒，抬眼扫过墙角的货箱。
△ 陈峰靠在货箱上没动，把烟头在铁栏杆上摁灭。
△ 林辰抬脚踢开挡路的空塑料筐，径直走向陈峰。
林辰（冷笑）：三年了，你们欠我的，该还了。
陈峰（别过脸）：你疯了？
```

切出的分镜正文：

```
顶光从铁门缝隙切进来，照在湿漉漉的水泥地上，雨水顺着门缝往里渗。
@[林辰] 侧身挤开半掩的铁门，夹克肩膀浸出深色，在门口顿了一秒，抬眼扫过墙角的货箱。
@[陈峰] 靠在货箱上没动，把烟头在铁栏杆上摁灭。
@[林辰] 抬脚踢开挡路的空塑料筐，径直走向陈峰，冷笑。
@[林辰]{三年了，你们欠我的，该还了。}
@[陈峰] 别过脸。
@[陈峰]{你疯了？}
```

| 工厂原文 | 正文处理 |
|---|---|
| `[场景]` 行 | 环境细节进动作拍；场景名用于登记资产 |
| `[人物]` 行 | 只登记资产；正文首次出现写 `@[名字]` |
| `△` 动作行 | 逐拍保留，一句一行，不合并、不概括 |
| `角色（神态）：台词` | 神态单独成一个动作拍；台词 `@[角色]{台词}` |
| 旁白 / 画外音 | 裸 `{台词}` |
| 镜头走法 | 原文写了（推、拉、摇、移）就保留，没写就空着，不编 |

## 五、时长

- `【本集时长】：120 秒` 是这一集的预算；
- 按拍数均摊，每段 12~15 秒，总和可能不等于预算（不劈断台词，只能微调），差额写进回执；
- 只做内容节奏切分，不对齐任何模型档位。

## 六、产出

`scripts/episode_N.json`，每个分镜：

| 字段 | 内容 |
|---|---|
| `scene_id` | `E1S01`、`E1S02`… |
| `duration_seconds` | 12~15 |
| `text` | 这段视频的描述（正文） |
| `utterances` | 台词条目（说话人 + 文本） |
| `characters_in_scene` / `scenes`（/ `props`） | 该段引用的资产名 |
| `source_text` | 对应的工厂原文行，供对照与重导 |
