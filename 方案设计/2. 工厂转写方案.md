# 短剧工厂转写方案

> 读工厂单集原文 → 切分镜 → 写 `scripts/episode_N.json`。
> 分镜 = 一段视频的描述。视觉一致性由角色/场景/道具的资产图（参考图）提供，分镜图不是前置产物。

## 一、概念定义

| 概念 | 定义 |
|---|---|
| **分镜** | 脚本里可独立生成的一段视频。正文就是这段视频的描述：谁、在哪、发生什么、镜头怎么走、什么声音。 |
| **分镜正文** | 该段视频的唯一内容真相。不含「第一帧画什么」这种静态拆分。 |
| **台词** | 分镜的一个字段（`utterances`）：谁说的、说了什么。供配音、字幕、口型使用；正文里用归属记号标注说话人。 |
| **资产** | 角色 / 场景 / 道具。每个资产有名字 + 外观描述，外观描述用于生成资产图。 |
| **参考图** | 资产图。出视频时随分镜一起下发，负责人物长相、服装、环境、道具的一致性。 |
| **切分镜** | 把工厂单集原文按拍（动作行 / 台词行）切成 N 段，每段 12~15 秒。 |

分镜与参考图的分工：**分镜说这一段视频里发生什么，参考图说画面里的人和环境长什么样。**

## 二、转写做什么

1. 读 `source/short_drama/episodes/episode_NN.md`；
2. 按 `[场景]` 块 / `△` 动作行 / `角色（神态）：台词` 行切分镜，每段落在 12~15 秒的内容窗口内（`STORY_SCENE_WINDOW_SECONDS`）；切点只落在拍与拍之间，不劈断台词；
3. 每段分镜写三样东西：
   - `text`：这段视频的描述（场景 + 动作 + 神态 + 光线氛围，台词以 `@[角色]{台词}` 形式嵌入）；
   - `utterances`：从原文台词派生，逐字保留；
   - 引用：`characters_in_scene` / `scenes`（有道具则含 `props`），用于派生参考图；
4. 登记资产：名字 + 外观描述写进 `project.json`，已存在的不覆盖；
5. 回执：分镜数、总时长与 `【本集时长】` 的差额、缺描述的资产清单。

转写不写提示词、不生成任何图片、不生成视频。

## 三、分镜正文怎么写

以工厂原文为例：

```
【本集时长】：120 秒
[场景]：城郊仓库｜水泥地、铁门、单侧顶光
[人物]：林辰（隐忍龙王｜三十岁上下，寸头，旧夹克）、陈峰（嚣张富二代）
△ 林辰推开门，雨水顺着脸颊滴落。
林辰（冷笑）：三年了，你们欠我的，该还了。
陈峰：你疯了？
```

切出的分镜正文：

```
夜，城郊仓库内，水泥地被雨水打湿，铁门半开，单侧顶光从门缝切进来。
@[林辰] 推门而入，雨水顺着脸颊滴落，镜头由中景缓推至近景。
@[林辰]{三年了，你们欠我的，该还了。}
@[陈峰]{你疯了？}
```

规则：

| 工厂原文 | 正文里的处理 |
|---|---|
| `[场景]` 行 | 作为段落开头的环境描述；外观细节归资产，不重复写进正文 |
| `[人物]` 行 | 只用于登记资产；正文里首次出现写 `@[名字]` |
| `△` 动作行 | 动作句，原样保留 |
| `角色（神态）：台词` | 神态并入动作描述，台词写成 `@[角色]{台词}` |
| 旁白 / 画外音 | 裸 `{台词}` |
| 镜头走法 | 原文没写就不写；写了（推、拉、摇、移）原样保留。不替模型编机位 |

## 四、资产描述从哪来

三个来源，按优先级：

1. 单集 `[人物]` / `[场景]` 行括号内 `｜` 之后的外观段；
2. 该集没写全时，取 `character-bible.md` 中该角色的设定段、`series-outline.md` 的场景基调；
3. 仍缺的部分按题材补全（成本低、覆盖全），但补完的必须能追溯到 1 或 2，凭空编的关键设定不入库。

道具：工厂格式目前没有道具标记行。方案里增加 `[道具]：名称｜外观` 一行，转写按 `[场景]` 的方式解析登记；没有这行的集，道具为空，后续在资产管理里补。

## 五、时长

- `【本集时长】：120 秒` 是这一集的预算；
- 按拍数均摊，每段 12~15 秒，总和可能不等于预算（不劈断台词，只能微调）；
- 差额写进回执，不静默吞掉；
- 此处只做内容节奏的切分，不对齐任何模型的档位。

## 六、产出

`scripts/episode_N.json`：

| 字段 | 内容 |
|---|---|
| `scene_id` | `E1S01`、`E1S02`… |
| `duration_seconds` | 12~15 |
| `text` | 这段视频的描述 |
| `utterances` | 台词条目（说话人 + 文本） |
| `characters_in_scene` / `scenes` / `props` | 参考图来源 |
| `source_text` | 对应的工厂原文行，供对照与重导 |

不含 `image_prompt`、`video_prompt`、`storyboard_image`。

## 七、待定

1. 分镜正文的镜头走法：原文没写时，转写阶段留空、由后续提示词环节补，还是转写时按剧情补？
2. 道具：工厂模板加 `[道具]` 行（推荐），还是靠资产补全 + 人工新增？
3. 缺失资产描述的补全：转写后给一个批量入口（推荐），还是转写时顺带补？
