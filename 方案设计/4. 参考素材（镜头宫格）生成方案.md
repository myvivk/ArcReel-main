# 4. 参考素材（镜头宫格）生成方案

> 本步骤把唯一动态分镜提示词渲染成按时间排序的 K 帧。它不生成或改写第二份视频提示词。

## 一、流程位置

```text
AI 分镜生成 image_prompt
  → 配置 ShotGrid 规格与逐格文本
  → 生成联系表并切分 K0…Kn
  → 用户逐镜确认
  → reference/r2v 视频生成
```

参考素材不修改工厂 Markdown 源稿，也不反向改写 `image_prompt`。

## 二、输入

| 输入 | 来源 | 用途 |
| --- | --- | --- |
| `image_prompt.scene` | AI 分镜或显式提示词重写 | 提取关键动作、转折、入场、失态和稳定落点 |
| 出场资产清单 | 分镜条目 | 限定合法角色、场景、道具 |
| 资产图 | 项目资产表 | 保持身份、空间和道具一致性 |
| ShotGrid 规格 | 2×2、2×3、3×3 等 | 决定 K 帧数量 |
| 项目风格与比例 | 项目设置 | 统一画面风格 |

叙事镜头数与宫格格数不要求相等。系统按动态提示词中的可见状态变化映射到固定格数，可以同镜多帧，也可以合并次要过渡。

## 三、逐格文本

每格只描述一个冻结瞬间：

- 写清主体姿态、表情、位置、持物、构图、光线和可见环境。
- 不写镜头运动、先后动作、渐变过程或台词原句。
- K0 对应动态提示词的起始状态，Kn 对应动作完成后的稳定定姿。
- 中间格优先选择剧情转折、入场、失态、关系变化和断章前的可见瞬间。
- 逐格 token 只能引用本镜出场资产。

`ShotGrid.prompt` 可以由用户编辑或由 `author_shot_grid_prompt` 生成；批量路径可直接从 `image_prompt.scene` 解析。生成时实际使用的逐格文本写入 `cells[].prompt`，用于审计和请求证据。

## 四、生成与确认

1. 保存 ShotGrid 草稿后才能生成；取消、Esc 或关闭不落盘。
2. 规格与逐格数量必须严格一致，不截尾、不自动补格。
3. 生成得到一张完整联系表，并切分为按时序排序的 `cell_paths`。
4. 用户确认时，在同一事务中校验联系表、切图、路径、规格和视觉状态，并写入分镜的 `generated_assets.shot_grid` 绑定。
5. 解除确认只解绑消费资格，保留宫格记录与图片。

视频消费只认完整 confirmed 绑定：

- `grid_id` 非空。
- `confirmed_at` 非空。
- `cell_paths` 非空且每项路径有效。
- 宫格记录与当前分镜、集号、脚本文件一致。

completed 记录可供页面评测和重新确认，但不能直接进入视频请求。

## 五、选择与多版本

同一分镜存在多条 ShotGrid 记录时，按以下顺序选择：

1. 分镜显式绑定的记录。
2. confirmed 记录。
3. completed 记录。
4. 最近更新记录。

绑定缺失或无效时，不冒用另一条记录生成视频。工作流、批量准入、单条生成、预览和 worker 使用同一选择与校验口径。

## 六、时效

- `image_prompt`、引用资产图或项目视觉事实变化后，当前参考素材 stale。
- 重新生成或重新确认参考素材后，已有视频 stale。
- 参考素材变化不改写 `image_prompt`。
- 重新生成前已有 confirmed K 帧仍可查看；是否重做由用户明确决定。

## 七、工作流与界面

制作进度只保留 `shot_grid` 行，不再有 `video_prompt` 行。

分镜详情的「参考素材」区负责配置、生成、轮询、展示、确认和取消确认。确认完成后，视频按钮直接使用当前动态提示词与 confirmed K 帧；视频弹窗不提供提示词编辑和帧模式选择。

## 八、验收标准

1. 参考素材只从 `image_prompt` 与合法资产生成。
2. 每格是冻结瞬间，K0…Kn 顺序稳定且可审计。
3. 未确认、绑定不完整、路径无效或过期的宫格不能进入视频准入。
4. confirmed 宫格变化只使视频过期，不产生或重写任何文本字段。
5. 批量和单条入口对同一 ShotGrid 得出相同选择、参考图顺序和拒绝原因。
