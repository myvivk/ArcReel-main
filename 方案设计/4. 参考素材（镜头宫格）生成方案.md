# 4. 参考素材（镜头宫格）生成方案

> 本方案只定义「参考素材」步骤：把已生成的分镜提示词渲染成宫格图，确认后切成按 `K0…Kn` 排序的关键帧素材。`video_prompt` 的编写属于下一步，见《5. 视频提示词独立步骤生成设计》。

## 一、步骤边界

参考素材步骤位于「AI 分镜」之后、「视频提示词」之前。

```text
source/short_drama/episodes/episode_NN.md
        ↓
AI 分镜生成分镜段与 image_prompt.scene
        ↓
参考素材步骤：生成 ShotGrid → 出宫格图 → 用户确认 → 切出 K0…Kn
        ↓
视频提示词步骤读取 image_prompt.scene + 已确认 K 帧文本
```

本步骤不修改短剧工厂 Markdown 源稿。当前实现从视觉制作派生状态中读取分镜段和 `image_prompt.scene`；该派生状态不能被定义为工厂真相源，也不能反向覆盖 `source/short_drama/episodes/episode_NN.md`。

## 二、输入

| 输入 | 来源 | 用途 |
| --- | --- | --- |
| 分镜段 ID | AI 分镜结果或人工分镜 | 定位要生成参考素材的分镜 |
| `image_prompt.scene` | AI 分镜步骤产出的 12-15 秒分镜段画面提示词 | 解析逐格画面意图 |
| `ShotGrid.prompt` | 单分镜弹窗内用户手填或 AI 生成的宫格提示词，可为空 | 单分镜生成时优先使用；为空时回退 `image_prompt.scene` |
| `rows` / `cols` | 单分镜弹窗选择；整集批量固定值 | 决定宫格规格与格数 |
| 项目画布比例 | 项目 `aspect_ratio` | 计算整张宫格和单格比例，支持 16:9 与 9:16 |
| 角色 / 场景 / 道具资产图 | 资产步骤产出的资产图 | 作为图像模型参考图，保证人物、场景和道具一致 |

`image_prompt.scene` 描述的是一段 12-15 秒画面内容，可以包含多个 `【镜头N】` 块。它不是单帧画面说明，也不要求叙事镜头数与宫格格数相同。

## 三、产出

| 产出 | 落点 | 说明 |
| --- | --- | --- |
| `ShotGrid` 记录 | `shot_grids/shot_grid_*.json` | 保存规格、状态、提示词草稿、逐格文本留证和图片路径 |
| 宫格图 | `ShotGrid.composite_path` | 一张 N×M 联合图，无边框、无文字、无序号 |
| 逐格文本 | `ShotGrid.cells[].prompt` | 本次出图实际使用的逐格画面文本，只作留证和下游文本代理 |
| 逐格景别 / 连续性备注 | `ShotGrid.cells[].continuity_notes` | 供下游展示和视频提示词上下文使用 |
| K 帧切图 | `ShotGrid.cell_paths` | 用户确认后按阅读顺序切出 `K0…Kn` |
| 分镜图绑定 | `generated_assets.shot_grid` / `storyboard_image` | 当前实现会把确认后的宫格与切图绑定到视觉制作状态 |

本步骤不产出以下内容：

- 不生成或修改 `video_prompt`。
- 不生成视频文件。
- 不修改 `source/short_drama/episodes/episode_NN.md`。
- 不登记新资产，不生成资产描述。
- 不根据视频模型能力改写分镜提示词。

## 四、提示词拼装规则

图像模型收到的宫格提示词由系统拼装，不把排版参数交给用户手写。

| 段落 | 来源 | 写入者 |
| --- | --- | --- |
| 布局要求 | `rows` / `cols`、项目画布比例、阅读顺序 | 系统 |
| 风格与锚点 | 项目风格块、资产参考图声明、分镜提示词导语 | 系统 |
| 逐格画面 | `ShotGrid.prompt` 优先；为空时解析 `image_prompt.scene` | 用户可选 / 系统解析 |
| 纯净性约束 | 无文字、无序号、无气泡、无箭头、无水印 | 系统 |

关键规则：

1. 排版、比例、阅读顺序和纯净性约束只由系统拼装。用户输入框只写逐格画面意图。
2. 宫格图必须无边框、无间隙、无留白。确认切图会等分裁剪，边框会污染每个 K 帧。
3. 资产外观以资产图为准。提示词只写跨格连续要求，例如同一套服装、同一时段、同一光线方向。
4. 生成后把本次实际使用的逐格文本写入 `cells[].prompt`，用于审计和下游 `video_prompt` 输入；用户不在 `cells` 上二次编辑。

## 五、单分镜流程

单分镜入口在分镜详情页的「参考素材」区。

```text
点击「配置参考素材」
        ↓
打开 ShotGridDialog
        ↓
选择规格（2×2 / 2×3 / 3×3，默认 2×2）
        ↓
可选：手填宫格提示词，或点击「AI 生成」生成可编辑草稿
        ↓
点击「确定」
        ↓
saveShotGrid(prompt, rows, cols)
        ↓
enqueueShotGrid
        ↓
任务完成后展示宫格图
        ↓
用户点击「确认参考素材」
        ↓
系统切出 K0…Kn 并写回视觉制作状态
```

交互约束：

- 已确认的宫格锁定规格。要更换规格，先取消确认，再重新生成。
- `ShotGrid.prompt` 可为空。为空时使用 `image_prompt.scene` 解析逐格文本。
- 手写逐格提示词时，解析出的格数必须与 `rows × cols` 一致；不一致时阻断提交。
- 「AI 生成」只返回可编辑草稿，不直接入队生成图片。
- 重新生成宫格不修改 `image_prompt.scene`，也不合并旧格内容。

## 六、整集批量流程

整集入口在制作进度的「参考素材」行。

```text
点击「批量生成参考素材」
        ↓
服务端预览目标集合与跳过原因
        ↓
用户确认
        ↓
为每个目标分镜创建 shot_grid 任务
        ↓
任务完成后在分镜详情页逐个确认参考素材
```

批量规则：

- 规格固定为 2×2。
- 不弹出宫格提示词输入框。
- 不保存 `ShotGrid.prompt`。
- 逐格文本统一从 `image_prompt.scene` 解析。
- 每个目标分镜一个 `shot_grid` 任务，实际并发由现有生成队列控制。

跳过原因：

| 原因 | 触发条件 | 恢复方式 |
| --- | --- | --- |
| `missing_prompt` | `image_prompt.scene` 为空或仍待编写 | 先执行 AI 分镜或补齐分镜提示词 |
| `reference_unavailable` | 引用的角色 / 场景 / 道具没有可用资产图 | 先完成资产步骤 |
| `generating` | 该分镜已有参考素材任务运行中 | 等待任务完成 |
| `confirmed` | 该分镜已有已确认参考素材 | 如需重做，单分镜取消确认后重新生成 |

## 七、页面与工作流

制作进度新增 `shot_grid` 行，位于 `storyboard` 之后、`video_prompt` 之前。

```python
_STEP_IDS = (
    ...,
    "asset_sheets",
    "script_structure",
    "storyboard",
    "shot_grid",
    "video_prompt",
    "video",
    "edit",
)
```

工作流口径：

| 项 | 规则 |
| --- | --- |
| 行标题 | 复用「参考素材」 |
| 适用条件 | 与 `storyboard` 相同，只在 `generation_mode == "storyboard"` 时适用 |
| 完成条件 | 本集应有参考素材的分镜都存在可用 `ShotGrid`，且没有缺失项 |
| 任务归行 | `shot_grid` 任务归 `shot_grid` 行 |
| 下一步 | 参考素材确认完成后进入 `video_prompt` 步骤 |
| 状态来源 | 按 `ShotGridManager` 记录和 `image_basis` 时效判断，不复用 `storyboard_image` 产物集合 |

分镜详情页保留「参考素材」区，负责配置、生成、轮询、展示、确认和取消确认。确认完成后，下游视频提示词步骤读取 `ShotGrid.cells` 和 `cell_paths`，但不在本步骤中写 `video_prompt`。

## 八、API 与数据模型

### 8.1 数据模型

`ShotGrid` 至少保存：

```python
@dataclass
class ShotGrid:
    id: str
    shot_id: str
    rows: int
    cols: int
    status: str
    prompt: str = ""
    scene_revision: str | None = None
    composite_path: str | None = None
    cell_paths: tuple[str, ...] = ()
    cells: tuple[ShotGridCell, ...] = ()
    video_aspect_ratio: str | None = None
```

`prompt` 是单分镜弹窗的可编辑逐格提示词。批量路径合法为空。`scene_revision` 记录生成草稿时的 `image_prompt.scene` 指纹，用于判断草稿是否过期。

### 8.2 端点

| 端点 | 职责 |
| --- | --- |
| `PUT /projects/{project_name}/shot-grids` | 保存单分镜宫格草稿、规格和提示词 |
| `POST /projects/{project_name}/shot-grids/author-prompt` | 根据分镜、规格和资产上下文生成可编辑宫格提示词 |
| `POST /projects/{project_name}/shot-grids/generate` | 根据 `ShotGrid.prompt` 或 `image_prompt.scene` 入队生成宫格图 |
| `POST /projects/{project_name}/shot-grids/{grid_id}/confirm` | 确认宫格、切出 `K0…Kn`、写回视觉制作状态 |
| `POST /projects/{project_name}/episodes/{episode}/shot-grids/batch/preview` | 预览整集批量目标与跳过原因 |
| `POST /projects/{project_name}/episodes/{episode}/shot-grids/batch` | 创建整集参考素材批量任务 |

## 九、失败与恢复

| 失败类型 | 触发条件 | 恢复方式 |
| --- | --- | --- |
| 缺少分镜提示词 | `image_prompt.scene` 为空 | 回到 AI 分镜步骤生成或编辑分镜提示词 |
| 缺少资产图 | 分镜引用的资产没有可用图 | 回到资产步骤生成资产图 |
| 手写格数不匹配 | `ShotGrid.prompt` 解析出的格数不等于 `rows × cols` | 修改提示词或规格后重新提交 |
| 生成任务失败 | 图像模型失败、队列失败或文件写入失败 | 保留草稿，允许重试 |
| 确认切图失败 | 宫格图片不可读、尺寸异常或切分失败 | 重新生成宫格图 |
| 参考素材过期 | 分镜提示词或资产图变化后，现有宫格不再匹配 | 标记过期，允许重新生成 |

失败恢复不得修改工厂 Markdown 源稿。需要修改剧情、对白或资产标记时，应回到工厂源稿编辑 / 重导入流程，而不是在参考素材步骤里补写。

## 十一、测试与验收

建议测试：

- `ShotGrid` 保存：相同规格保存不清空已生成结果；改规格才重置；已确认状态拒绝改规格。
- 单分镜弹窗：AI 生成草稿、手动编辑、格数校验、取消不写入、确定后保存并入队。
- 批量规划：缺 `image_prompt`、缺资产图、已有任务、已确认宫格四类跳过原因。
- 提示词拼装：布局、比例、纯净性约束由系统拼装；用户提示词只进入逐格画面段。
- 确认切图：按 `rows × cols` 切出 `K0…Kn`，路径写回 `cell_paths`。
- 工作流：`shot_grid` 行位于 `storyboard` 与 `video_prompt` 之间，任务归行正确。

验收标准：

1. 单分镜能选择 2×2、2×3、3×3 规格并生成参考素材。
2. 整集批量能为缺失参考素材的分镜创建任务，不弹出提示词编辑框。
3. 已确认参考素材后，`ShotGrid.cells` 与 `cell_paths` 可被视频提示词步骤读取。
4. 本步骤不写 `video_prompt`，不生成视频，不修改工厂 Markdown 源稿。
5. 页面能清楚显示未生成、生成中、已生成、已确认、失败和过期状态。
