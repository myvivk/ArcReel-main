# 5. 独立视频提示词步骤取消设计

## 一、结论

独立视频提示词步骤已取消。生产链路不再生成、编辑、评分或等待 `video_prompt`：

```text
工厂源稿 → 资产 → AI 分镜（唯一动态 image_prompt）→ 参考素材确认 → 视频
```

`image_prompt` 在 AI 分镜阶段一次确定剧情、表演、动作、调度、画面、光线和声音。参考素材从中抽取 K 帧，视频生成直接消费同一文本与实际参考图，避免 K 帧确认后再次使用 AI 改写而造成剧情漂移。

## 二、删除范围

- 删除工作流动作 `AUTHOR_VIDEO_PROMPTS` / `author_video_prompts`。
- 删除制作进度中的视频提示词行。
- 删除 `fields=["video_prompt"]` 的 API、Agent 和前端入口。
- 删除分镜详情中的视频提示词编辑区、模型选择和独立评分面板。
- 删除视频弹窗中的临时提示词编辑能力。
- 删除新流程对 `video_prompt_basis` 的写入、比较和 stale 判断。
- 视频批量规划不再以 `video_prompt` 是否为空决定目标。

## 三、历史兼容

`video_prompt` 与 `generated_assets.video_prompt_basis` 仍可存在于历史 JSON，并由存储模型无损读取。兼容边界只有读取：

- 不作为提示词编写字段。
- 不允许 Agent 通过 `patch_episode_script` 更新。
- 不参与参考素材或视频准入。
- 不参与视频请求组装。
- 不参与 Artifact Manifest 时效。
- 不在公开 UI 和工作流中展示。

兼容字段不是新流程的双写目标，也不要求迁移时补齐或清空。

## 四、唯一提示词的下游消费

参考素材和视频统一通过 `storyboard_motion_prompt(item)` 读取 `image_prompt.scene` 或兼容文本形态。生成前用 `storyboard_motion_prompt_item_problem` 校验：

- 镜头格式和连续编号。
- 资产 token 与本镜出场清单。
- 从 0 秒开始的连续时间轴。
- 每镜以时间码开头、首句写机位与运镜，并以「画面：」「声音：」标记收尾（fea_1026 视频提示词写法）；历史四层标签（主体动态 / 空间调度 / 画面与光线 / 声音）仍兼容校验。
- 禁止前向引用 K 帧。

修改 `image_prompt` 会使参考素材与视频过期；修改 confirmed 参考素材只使视频过期。

## 五、验收标准

1. 新项目即使没有 `video_prompt` 字段，也能完成参考素材和视频生成。
2. 任何公开入口都不能请求、编辑或重写 `video_prompt`。
3. 历史字段存在或内容不合法时，不会阻断使用合法 `image_prompt` 的新视频请求。
4. 工作流从参考素材确认直接进入视频生成。
