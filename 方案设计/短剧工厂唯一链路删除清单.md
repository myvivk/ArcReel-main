## 1. 删除范围

按最新要求，短剧工厂成为唯一创作及制作链路：

```text
创意简报 / 工厂续写 / 工厂工件导入
    ↓
工厂生成、医生精修、机检、合规、返修
    ↓
七类 Markdown 工件原样入库
    ↓
本集资产 → AI 分镜 → 参考素材 K 帧确认 → 独立视频提示词 → 视频生成
    ↓
剪辑、预览、成片与导出
```

剧情、台词和系列设定以 `source/short_drama/` 为真相源；`scripts/episode_N.json` 继续承载视觉制作派生状态。项目仍可使用真人或动画视觉风格。

拟删除的其它链路包括：

1. 小说或普通原文上传、整本分集、单集原文确认、原生脚本规划及内容确认。
2. 旁白 / 解说创作模式 `narration`。
3. 广告 / 短片创作模式 `ad`，包括商品、卖点和广告脚本。
4. 参考生视频项目路线 `reference_video`。
5. 旧多宫格分镜装配：多个分镜联合出图，再切出各分镜单帧。
6. 旧单集 / 批量 Markdown 转 JSON 导入、机械分镜生产、空白 JSON 剧本起步。
7. 上述链路的页面按钮、弹窗、URL 参数、API、任务入口、Agent 工具和引导文案。

方案和工程文档中原有的「保留旧入口兼容」条款，需要按这次唯一链路要求同步收口。删除对象是生产链路和代码入口，历史项目文件的删除、转换及迁移不由本清单授权。

6. 清理仅测试被删链路的用例、mock 和 E2E fixture；保留并运行工厂与公共能力的回归。

### 验收

- 新建项目没有其它创作类型、参考生视频或旧联合图选项。

- 旧 HTTP 端点、MCP 工具和队列提交路径均已撤除；仅隐藏按钮或返回禁用提示不算完成源码删除。
- 工厂能完成「源稿 → 资产 → AI 分镜 → K 帧确认 → 独立视频提示词 → 视频 → 剪辑导出」。
- 工件质量闭环、只读源稿、工厂声音能力、K 帧完整关系、并发检查和失败恢复仍可用。
- 工厂没有正文或缺资产描述时进入对应工厂步骤，不回退到原生脚本规划、空白 JSON 或机械分镜。
